# Сон и яркость

Простое приложение для Android TV: выключает телевизор по таймеру и затемняет экран сильнее, чем позволяют обычные настройки. Удобно ночью.

- Таймер: 5, 10, 20, 30, 40, 50 минут, 1 час, 1,5, 2, 2,5, 3 часа. Есть кнопка «Отменить таймер».
- Ползунок яркости: шаг 5%, от 100% до 5%. Затемнение остаётся поверх любого приложения — YouTube, Кинопоиск и т. д.
- Когда телевизор включается снова, яркость возвращается сама. Можно и вручную — кнопкой «Вернуть яркость».
- Приложению не нужен интернет, оно никуда ничего не отправляет.

## Подойдёт ли мой телевизор

Да, если это **Android TV или Google TV**, Android 8 и новее: Haier, Xiaomi, TCL, Sony, Philips, Hisense на Android, приставки Mi Box, Chromecast с Google TV и т. п.

Нет, если это **LG (webOS)** или **Samsung (Tizen)**: на них APK не ставится.

## Установка

Скачайте готовый файл [`tvsleep.apk`](tvsleep.apk) из этого репозитория — ничего собирать не нужно. Поставить его на телевизор можно любым способом:

**Через флешку**
1. Скопируйте `tvsleep.apk` на флешку и вставьте её в телевизор.
2. Откройте флешку в файловом менеджере на телевизоре (например, File Commander или X-plore из Google Play).
3. Выберите `tvsleep.apk` → «Установить».
4. Если телевизор спросит про установку из неизвестных источников — разрешите это файловому менеджеру.

**Через телефон**
1. Поставьте на телефон и телевизор приложение **Send Files to TV** из Google Play.
2. Отправьте `tvsleep.apk` с телефона на телевизор.
3. На телевизоре откройте полученный файл → «Установить».

После установки в списке приложений появится **«Сон и яркость»** (значок с месяцем).

## Разрешения — включить один раз

Без них приложение откроется, но работать не будет. Названия пунктов на разных телевизорах немного отличаются.

**1. Поверх других приложений** — без этого не будет затемнения.

Настройки → Приложения → Специальный доступ → **Поверх других приложений** → «Сон и яркость» → Вкл.

**2. Специальные возможности** — без этого таймер не сможет выключить телевизор.

Настройки → Настройки устройства → **Специальные возможности** → «Сон и яркость» → Вкл.

Телевизор предупредит, что приложению будет доступен весь экран. Это стандартное предупреждение Android. Приложение использует это право только для одного действия — отправить телевизор в сон — и ничего с экрана не читает.

**3. Изменение системных настроек** — необязательно.

Настройки → Приложения → Специальный доступ → **Изменение системных настроек** → «Сон и яркость» → Вкл.

Тогда приложение вместе с затемнением будет понижать и системную яркость. Если такого пункта нет — ничего страшного, затемнение работает и без него. Надпись «Нет права менять яркость» в приложении в этом случае можно не замечать.

Если в приложении внизу есть оранжевая надпись — значит, какое-то из разрешений не включено.

## Как пользоваться

1. Откройте «Сон и яркость».
2. Выберите таймер — сверху появится обратный отсчёт.
3. Стрелками **влево/вправо** на ползунке убавьте яркость.
4. Нажмите «Назад» или «Домой» и смотрите что угодно — таймер и затемнение продолжат работать.

Когда таймер закончится, телевизор уйдёт в сон. Утром включите его как обычно — яркость будет нормальной.

## Если что-то не так

- **Таймер перестал выключать телевизор** после обновления приложения — Android сам выключает «Специальные возможности» при обновлении. Включите пункт 2 заново.
- **Нет пункта «Поверх других приложений»** — на некоторых телевизорах он скрыт. Тогда разрешение можно выдать только с компьютера, см. ниже.

## Для продвинутых: выдать разрешения с компьютера

Нужен `adb` и включённая «Отладка по сети» в меню «Для разработчиков» на телевизоре.

```bash
adb connect <IP телевизора>:5555
adb install tvsleep.apk
adb shell appops set local.tvsleep SYSTEM_ALERT_WINDOW allow
adb shell appops set local.tvsleep WRITE_SETTINGS allow
adb shell settings put secure enabled_accessibility_services local.tvsleep/local.tvsleep.SleepService
adb shell settings put secure accessibility_enabled 1
```

Только для телевизоров **Haier** — чтобы приложение понижало ещё и подсветку из меню изображения:

```bash
adb shell pm grant local.tvsleep android.permission.WRITE_SECURE_SETTINGS
```

Последняя команда заменяет список включённых специальных возможностей. Если на телевизоре уже включены другие — допишите `local.tvsleep/local.tvsleep.SleepService` к ним через двоеточие.

## Сборка из исходников

Нужны JDK 17 и Android SDK (platform 34, build-tools 34). Пути к ним прописаны в `build.sh`. Сборка:

```bash
./build.sh
```

Готовый файл — `build/tvsleep.apk`. При первой сборке создаётся ключ подписи `release.keystore`. Храните его: без него обновить уже установленное приложение не получится.
